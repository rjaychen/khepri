# Khepri

> *"From raw particles and silent sands, entire worlds arise."*

**Khepri** is an experimental graphics programming sandbox and real-time laboratory powered by C++20 and modern Vulkan.

---

## Current Focus

The project focuses on low-level GPU compute, real-time animation, and high-density particle simulations using custom half-edge mesh structures and procedural deformation graphs. 

## Features to be added:

- Modern raycasting optimizations
